# 🎵 VibeSpeak — TeamSpeak 6 MusicBot (Яндекс.Музыка & Радио)

Легковесный, надежный и функциональный музыкальный бот для **TeamSpeak 6** и **TeamSpeak 3** с поддержкой **Яндекс.Музыки** (полные треки, альбомы, плейлисты), **умной очереди воспроизведения**, **зацикливания треков** и проверенных **Интернет-радиостанций** (включая 24/7 Lo-Fi Hip Hop).

> 🚫 **Примечание:** Сервисы **YouTube**, **SoundCloud** и **ВК Музыка** полностью отключены и заблокированы. Бот работает исключительно с **Яндекс.Музыкой** и **Интернет-радио**.

Полностью готов к работе как на **VPS / VDS серверах под управлением Debian 10/11/12 и Ubuntu 20.04/22.04/24.04** (потребляет всего **~50–80 МБ RAM**), так и для локального запуска на **Windows**.

## ✨ Возможности и особенности

* **🎧 Яндекс.Музыка**:
  * **Поиск треков**: по названию и артисту (например, `!play Король и Шут Лесник`). При поиске артиста автоматически выбирается его главный популярный хит.
  * **Прямые ссылки**: поддержка треков (`.../album/123/track/456`), альбомов (`.../album/123`) и плейлистов (`.../users/.../playlists/...`).
  * **Высокое качество звука**: прямой поток MP3 до 320 kbps без сжатия и задержек.
  * **Динамические обложки**: аватар бота автоматически меняется на обложку текущего трека или альбома.
  * **Воспроизведение треков целиком**: поддержка бесплатного токена без необходимости подписки Яндекс Плюс.
* **📋 Умная очередь треков (Queue)**:
  * Если музыка уже играет, команда `!play <трек>` **не прерывает текущую песню**, а аккуратно ставит новую в очередь: `➕ Добавлено в очередь (#1): ...`.
  * При добавлении альбома или плейлиста все треки автоматически помещаются в очередь.
  * Просмотр очереди по команде `!queue` (или `!q`) с таймингами и статусом повтора.
  * Пропуск треков по команде `!skip` (или `!next`).
  * Удаление определенного трека из очереди по номеру: `!remove <номер>`.
  * Автоматический переход к следующей песне при завершении текущей.
* **🔁 Зацикливание треков (Loop)**:
  * Команда `!loop` (или `!repeat`) включает бесконечный повтор текущего трека.
* **🤖 Мульти-боты по запросу (Multi-Bot on Demand)**:
  * **Основной бот `🎵 VibeSpeak`**: круглосуточно находится в основном канале (назначенном администратором), защищен от перемещения и отключения обычными пользователями.
  * **Временные боты по требованию**: если основной бот занят или пользователям в другом канале нужна музыка, любой пользователь может позвать бота в свой канал командой `!bot add` (создается `🎵 VibeSpeak #2`, `🎵 VibeSpeak #3` и т.д.).
  * **Автовыход (Auto-Leave)**: когда все пользователи покидают канал и он становится пустым, временный бот автоматически отключается через 20 секунд (не расходуя ресурсы сервера и слоты).
  * **Полная независимость**: каждый бот в каждом канале имеет отдельную независимую очередь, зацикливание, громкость и поток воспроизведения.
* **🔇 Чистый чат TeamSpeak 6 без спама**:
  * Ровно **одно красивое сообщение** в чат при воспроизведении или добавлении в очередь.
  * Никакого мусора, BBCode-тегов и красных ошибок прав.
* **🛡️ Автоматический вход и защита войса**:
  * Основной бот появляется на сервере сразу при старте (`connect = true`).
  * Обычные пользователи не могут перетащить или кикнуть основного бота (права защищены).
  * Основной бот играет именно в том канале, куда его определил администратор сервера.
* **📻 Интернет-радио (11 станций)**:
  * Команда `!radio` выводит нумерованный список станций на русском языке.
  * Станция **#1** — круглосуточный **Hunter FM Lo-Fi Hip Hop** (быстрый запуск по команде `!lofi`).
  * 11 стабильных радиостанций разных жанров (Lo-Fi, Chillhop, EDM, Клубная, Поп, Рок).
* **⚡ Поддержка команд через `!` и `/`**:
  * Любая команда работает как через восклицательный знак (`!play`, `!queue`, `!loop`, `!bot add`), так и через слэш (`/play`, `/queue`, `/loop`, `/bot add`).
* **🌐 Web-интерфейс**:
  * Управление воспроизведением через браузер по адресу `http://localhost:58913` (или `http://IP_VPS:58913`).

## 💬 Команды бота (на русском языке)

Все команды можно вводить как в чат канала, так и в личные сообщения боту. Команды автоматически применяются к тому боту, который находится в вашем канале.

| Команда | Короткий алиас | Описание |
|---|---|---|
| `!play <название>` | `!p <название>` | Включить песню (если музыка уже играет — добавить в очередь) |
| `!play <ссылка>` | `!p <ссылка>` | Воспроизведение трека, альбома или плейлиста по ссылке |
| `!queue` | `!q`, `!очередь` | Посмотреть текущую очередь треков, тайминги и статус повтора |
| `!loop` | `!repeat`, `!повтор` | Включить / выключить зацикливание текущего трека |
| `!skip` | `!next`, `!скип` | Пропустить текущий трек и включить следующий из очереди |
| `!remove <номер>` | `!del <номер>` | Удалить трек из очереди по номеру (например, `!remove 2`) |
| `!clear` | `!очистить` | Очистить очередь ожидания (текущий трек продолжит играть) |
| `!bot add` | `!bot new`, `!bot +` | Позвать временного бота в ваш канал (если основной занят) |
| `!bot remove` | `!bot kick`, `!bot del` | Отпустить временного бота из вашего канала вручную |
| `!bot list` | `!боты`, `!bots` | Показать список всех активных ботов, их каналов и статусов |
| `!radio` | `!радио` | Вывести список всех 11 доступных радиостанций с номерами |
| `!radio <1..11>` | `!r <1..11>` | Включить радиостанцию по номеру (например, `!radio 1`) |
| `!lofi` | `!лофи` | Быстрый запуск круглосуточного Lo-Fi Hip Hop (Станция #1) |
| `!pause` | `!пауза` | Пауза / продолжить воспроизведение |
| `!stop` | `!s`, `!стоп` | Полностью остановить музыку и сбросить очередь |
| `!volume <0..100>` | `!vol <0..100>` | Изменить громкость (или `!vol` без чисел — показать текущую) |
| `!song` | `!np`, `!трек` | Информация о текущем треке, времени и очереди |
| `!commands` | `!help`, `!помощь` | Вывести полную справку по всем командам |

*(Любую команду можно писать также со слэшем: `/play`, `/queue`, `/loop`, `/skip`, `/bot add`, `/radio 1`, `/stop`).*

## 🔑 Полные треки в Яндекс.Музыке (без лимита 30 секунд)

По умолчанию сервера Яндекс.Музыки отдают неавторизованным клиентам только 30-секундные демо-отрывки треков. Чтобы бот играл треки целиком от начала до конца:

> 💡 **Платная подписка «Яндекс Плюс» НЕ ТРЕБУЕТСЯ!** Подходит абсолютно любой бесплатный аккаунт Яндекс (даже только что зарегистрированный).

### Инструкция по получению токена за 15 секунд:
1. Откройте в браузере официальную страницу авторизации:  
   👉 **[Получить токен Яндекс.Музыки в 1 клик](https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d)**
2. Войдите в свой аккаунт Яндекс и нажмите **«Войти»** / **«Разрешить»**.
3. В адресной строке браузера появится адрес:
   ```text
   https://music.yandex.ru/#access_token=y0_AgAAAA...&token_type=bearer&expires_in=...
   ```
4. Скопируйте токен (начинается на `y0_...`) или всю ссылку целиком.
5. **Куда вставить токен:**
   * **На Windows**: Создайте файл `bot/yandex_token.txt` (можно скопировать из `bot/yandex_token.example.txt`) и вставьте полученный токен в него.
   * **На Linux VPS**: Поместите токен в файл `/opt/ts3audiobot/yandex_token.txt` (или в `debian-vps/config/yandex_token.txt`).
   * **Через переменную окружения**: Можно также задать системную переменную `YANDEX_MUSIC_TOKEN=y0_...`.
6. Перезапустите бота — теперь все треки будут воспроизводиться **целиком в наилучшем качестве (до 320 kbps MP3)**!

## 🐧 Установка на Linux Debian / Ubuntu (VPS)

Скрипт оптимизирован для работы на **Debian 10, 11, 12** и **Ubuntu 20.04, 22.04, 24.04 LTS**.  
Включает автоматическую установку совместимости с `.NET Core 3.1` (включая OpenSSL 1.1 / OpenSSL 3), настройку изолированного пользователя `ts3bot` и службу `systemd`.

1. **Склонируйте репозиторий на ваш VPS**:
   ```bash
   git clone https://github.com/Roskud/teamspeak-musicbot.git
   cd teamspeak-musicbot/debian-vps
   ```

2. **Запустите автоматическую установку от root**:
   ```bash
   chmod +x install.sh
   sudo ./install.sh
   ```

3. **Скрипт автоматически выполнит**:
   * Установку всех системных библиотек (`ffmpeg`, `libopus0`, `libasound2`, `python3`, `yandex-music`).
   * Настройку совместимости библиотек OpenSSL для Debian 12 / Ubuntu 22.04+.
   * Установку ядра бота в `/opt/ts3audiobot`.
   * Настройку прав доступа `rights.toml` и шлюза Яндекс.Музыки.
   * Создание и запуск фоновой службы `systemd` (`ts3audiobot.service`) с автозагрузкой.

4. **Управление службой на VPS**:
   ```bash
   sudo systemctl status ts3audiobot     # Проверить статус бота
   sudo journalctl -u ts3audiobot -f     # Просмотр логов в реальном времени
   sudo systemctl restart ts3audiobot    # Перезапуск бота
   sudo systemctl stop ts3audiobot       # Остановка бота
   ```
